## Before you start
- Open the home-screen app and tap **Update now** if offered (or close and reopen it).
- In Settings, fill in My details (name and title).
- Use an inspection with job details filled in (including client) and a few pins: two or more instructions (one with "Photo confirmation required" ticked) and an observation.

## Creating the memo
1. **Needs job details.** On an inspection with no job number or job name, **Create memo** is greyed out with a hint.
2. **Create.** On a complete inspection, tap **Create memo**: the editor opens with reference **SIM-001** (or the job's next number).
3. **Back on the home.** The Memo section now shows "SIM-001 · Site Instruction Memo" and **Open memo**.
4. **Next number.** A second inspection with the same job number gets SIM-002 when its memo is created.

## The editor
5. **Preview.** The branded memo appears beside the form in landscape and below it in portrait. It matches the Spike A sample's look.
6. **Live.** Change something (e.g. the salutation): the preview updates within a second.
7. **Job details shared.** Change "Item inspected" in the memo, go back to the inspection: it's changed there too, and in the notes box header.
8. **Recipients.** The client is the first "To". Add up to 5 recipients; To and Copy can't both be ticked; with no "To" a warning shows. The preview's table follows.
9. **Visit details.** Site visit requested by shows the client; Reason for visit shows the item inspected. Edit one: **Reset** puts the default back.
10. **Salutation.** Shows "Dear {first name}," of the first To recipient; edit and Reset work.
11. **Message.** Pick a different prefilled message: the text below changes. Edit the text: only this memo changes.
12. **Conditions.** "Ok to proceed subject to the following:", then "Complete items A–… listed below." and the photo condition (ticked because an item needs it), then the instructions A, B… Untick a condition: it leaves the preview.
13. **Reword.** Reword instruction A: "(reworded for this memo)" shows, the preview changes, the pin's text doesn't. **Use item text** goes back.
14. **Instructions follow the pins.** Add, delete or reorder pins on the drawing, then reopen the memo: the instructions list and letters follow.
15. **No instructions.** On an inspection with only observations, the memo says "Ok to proceed." with no list.
16. **Sign-off.** Name and title come from My details; edit them for this memo.
17. **Kept.** Force-quit and reopen the memo: everything is as you left it.

## Settings
18. **Prefilled messages.** Settings shows Memo messages, Standard conditions and Notes box heading. Edit a condition's text: memos show the new wording.
19. **Add / delete.** Add a memo message: new memos offer it. Delete one: it asks first.
20. **Spike panel gone.** The "Sample memo" panel is no longer in Settings.

## Other
21. **Offline.** Airplane mode: create a memo, edit it, and the preview still draws. Turn airplane mode off.
22. **Feel.** Anything in the memo wording or layout you want changed (free text).
